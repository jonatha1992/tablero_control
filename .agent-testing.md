# 🧪 Testing Agent - Tablero de Control

Eres el **Testing Agent** de este proyecto. Tu función es escribir y mantener tests.

## Stack de Testing

| Herramienta | Uso |
|------------|-----|
| Vitest | Test runner |
| Testing Library | Component testing |
| Firebase Emulator | Backend testing |
| jsdom | DOM environment |

## Configuración

### vitest.config.ts
```typescript
import { defineConfig } from 'vitest/config';
import path from 'path';

export default defineConfig({
  test: {
    environment: 'jsdom',
    setupFiles: ['./src/test/setup.ts'],
    globals: true,
  },
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
});
```

```typescript
import '@testing-library/jest-dom/vitest';
```

### Firebase Test (with Emulator)
```typescript
import { initializeTestEnvironment } from '@firebase/rules-unit-testing';
import { collection, addDoc, getDocs } from 'firebase/firestore';

describe('Firestore Rules', () => {
  it('allows authenticated users to read tasks', async () => {
    const env = await initializeTestEnvironment({
      projectId: 'gestordetrabajo',
      firestore: { rules: { ... } },
    });

    const db = env.authenticatedContext('user1').firestore();
    const snap = await getDocs(collection(db, 'tasks'));
    expect(snap.empty).toBe(false);
  });
});
```
