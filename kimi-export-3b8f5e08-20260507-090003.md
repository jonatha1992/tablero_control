## 1. Concepto

Un **Período de Trabajo** (`Cycle`) es una unidad temporal de planificación dentro de un negocio. Sirve para agrupar tareas por semanas, quincenas, sprints o meses. Cada ciclo pertenece a un `Business` y puede tener tareas asignadas.

---

## 2. Modelo de Datos (Prisma)

```prisma
model Cycle {
  id          String   @id @default(cuid())
  name        String
  goal        String?
  teamId      String?
  businessId  String
  status      String   @default("planning") // planning | active | completed | closed
  startDate   DateTime?
  endDate     DateTime?
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  tasks    Task[]
  business Business @relation(fields: [businessId], references: [id], onDelete: Cascade)

  @@index([businessId])
  @@index([status])
  @@index([startDate])
}
```

**Relaciones:**
- `Business` 1:N → `Cycle` (un negocio tiene muchos ciclos)
- `Cycle` 1:N → `Task` (un ciclo agrupa muchas tareas vía `task.cycleId`)

---

## 3. Estados del Ciclo

| Estado | Significado | Transiciones posibles |
|--------|-------------|----------------------|
| `planning` | En planificación, aún no iniciado | → `active` |
| `active` | En ejecución | → `completed` |
| `completed` | Finalizado exitosamente | → `closed` (implícito) |
| `closed` | Cerrado/archivado | — |

No hay validaciones automáticas que impidan saltar estados (ej: `planning` → `closed`), pero la UI solo expone botones de **Iniciar** (`planning→active`) y **Completar** (`active→completed`).
